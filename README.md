# Session File Actions｜会话附件操作插件

在聊天消息里选中附件，按 Ctrl+C，再到 Windows 资源管理器按 Ctrl+V，即可把文件粘贴到目标文件夹。也可以跨消息选中同一会话里的多份附件，一次保存。

**项目状态**　Windows 1.0 需求已定稿。DeepSeek Harness Desktop 和 OpenCode Desktop 的插件均尚未发布，以下介绍首版设计。

## 主要功能

- **复制文件与路径**　在原附件卡片上按 Ctrl+C 或右键选择「复制文件」，可粘贴出文件本身。「复制文件路径」则复制路径文本，多份文件每行一条。
- **跨消息选择与保存**　单击选中一项，Ctrl+单击增减选择，Shift+单击选择连续区间。多选后使用「另存为…」只需选择一次目录；重名文件会保留两份。
- **打开与定位**　双击使用默认应用打开文件，右键可选「打开方式」或「在资源管理器中定位」。多选时也可用共同支持的应用打开，或按所在目录分别定位。
- **悬停查看路径**　悬停显示附件关联的路径。右键菜单和路径提示跟随当前客户端的深浅主题；输入框有焦点或存在文本选区时，Ctrl+C 保留宿主的文本复制行为。

## 安装与验证

发布后，先在兼容表中找到自己的客户端版本，再使用对应的安装入口：

- **DeepSeek Harness Desktop**　在当前桌面 profile 的「插件 → 添加插件」中填入发布页提供的包名与版本，安装后点击「立即启用」。
- **OpenCode Desktop**　将发布页提供的包名与版本追加到全局 `opencode.json` 或 `opencode.jsonc` 的 `plugins` 数组，再到 **Settings → Extensions → Plugins** 确认已加载。

安装后，在会话中右键一份已知内容的附件，选择「复制文件」，到资源管理器的空文件夹按 Ctrl+V，核对文件名和内容。配置示例、本地验证包及升级、回退、卸载步骤见 [Windows 插件安装说明](./doc/会话附件操作插件需求Spec.md#12-windows-插件安装说明)。

## 使用示例

**把一份报告复制到文件夹。** 单击报告卡片，按 Ctrl+C，切到目标文件夹按 Ctrl+V。如果卡片关联了源文件路径，复制的是该路径在操作时的内容；只有会话副本时，复制消息保存的那一份。若关联的源路径已失效，插件会指出失败项并保留原剪贴板。

**把不同消息里的报告和表格一起保存。** 单击报告，按住 Ctrl 单击另一条消息里的表格，再右键任一已选卡片并选择「另存为…」。选一次目录即可保存两份文件。如果目录中已有「报告.pdf」，新文件会使用「报告 (2).pdf」等可用名称，完成提示会列出实际保存名。

## 支持平台与交付物

Windows 1.0 计划交付两份独立的预构建 npm 包。用户按客户端安装对应的一份。

| 目标客户端 | 插件作用的附件 | 发行与验证状态 |
|---|---|---|
| DeepSeek Harness Desktop | 当前会话中的上传附件和交付文件卡片 | 待发布、待 Windows 实测 |
| OpenCode Desktop | 当前会话中有路径引用或保存了文件内容的附件卡片 | 待发布、待 Windows 实测 |

发布时将列出两端的最低实测宿主版本。若某项能力依赖宿主补丁，兼容表会单独标明匹配的验证构建和验收结果。[最终交付物与完成条件](./doc/会话附件操作插件需求Spec.md#11-最终交付物与完成条件)
