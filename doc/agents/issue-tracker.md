# 本地 Markdown 任务跟踪

每项功能使用一个 `.scratch/<feature-slug>/` 目录。每张任务单独保存为 `issues/<NN>-<slug>.md`，在该功能内从 `01` 编号。

- 在文件顶部用 `Status:` 记录[任务分类](./triage-labels.md)，用 `Blocked by:` 列出同一功能内的前置任务编号，无依赖时写 `None`。
- 正文写清要交付的行为及可核对的验收条件。讨论和补充证据追加到文件末尾的 `## Comments`。
- 技能要求发布任务时，按上述路径创建本地文件。读取任务时，按给定路径或功能内编号查找。
- Windows 1.0 的任务单直接引用[定稿需求 Spec](../会话附件操作插件需求Spec.md)的相关章节，需求正文统一在该 Spec 中维护。
