# 09 从菜单和 Ctrl+C 复制整批文件

Status: ready-for-agent

Blocked by: 05, 06, 07, 08

阶段：三 · 用户操作与生命周期

## 交付结果

同一会话混选路径附件与会话副本，准备成功后一次发布全部文件。

依据：[§2](../../../doc/会话附件操作插件需求Spec.md#2-点击哪张卡片取得哪份文件)、[§3](../../../doc/会话附件操作插件需求Spec.md#3-卡片和操作对象)、[§4](../../../doc/会话附件操作插件需求Spec.md#4-批次反馈与生命周期)。对应验收用例 02、03、04、09。

## 验收条件

- [ ] 在两端分别粘贴跨消息同名异内容、同内容不同名的样本；按原名或安全后缀保留所有项并反馈映射。
- [ ] 已选 A、B 悬停 C 按 Ctrl+C 只得 A、B；右键 C 只得 C；已有独立按钮只复制所在项且不改选择。
- [ ] 无选择时悬停优先，再取焦点项；文本输入或离开附件上下文时交还宿主。
- [ ] 任一项失败整批不发布，不降级读取旧副本；不截获宿主已有的输入框文件粘贴。

## 分支、提交与合入

确认前置票 05、06、07、08 已合入 `windows-one` 后，从该集成分支开 `batch-copy`。

按可验证行为提交，相关实现、测试和必要文档同次提交。提交或 PR 标题示例：`feat(desktop-files): copy selected files`。合回 `windows-one` 前同步集成分支，复跑本票及受共享契约影响的验证。在 Comments 记录实际提交号、验证结果和证据位置。
