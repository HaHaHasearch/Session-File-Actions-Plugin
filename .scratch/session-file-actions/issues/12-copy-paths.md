# 12 复制可访问的文件路径

Status: ready-for-agent

Blocked by: 05, 06, 07, 08

阶段：三 · 用户操作与生命周期

## 交付结果

一次复制一条或多条真实可访问的本地路径文本。

依据：[§3](../../../doc/会话附件操作插件需求Spec.md#3-卡片和操作对象)、[§4](../../../doc/会话附件操作插件需求Spec.md#4-批次反馈与生命周期)。对应验收用例 07、10。

## 验收条件

- [ ] 本地源文件用原位置；远端或会话副本准备后标明本地副本。按会话顺序逐行写入纯文本。
- [ ] 任一项不可读则一次也不发布，保留原文本并指出失败项。
- [ ] 即使宿主退出，只要剪贴板文本仍引用这些路径就可访问；解除引用后再按宽限期回收，提示长期使用可另存为。

## 分支、提交与合入

确认前置票 05、06、07、08 已合入 `windows-one` 后，从该集成分支开 `copy-paths`。

按可验证行为提交，相关实现、测试和必要文档同次提交。提交或 PR 标题示例：`feat(desktop-files): copy attachment paths`。合回 `windows-one` 前同步集成分支，复跑本票及受共享契约影响的验证。在 Comments 记录实际提交号、验证结果和证据位置。
