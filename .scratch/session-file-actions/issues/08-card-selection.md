# 08 跨消息选择、键盘焦点与路径提示

Status: ready-for-agent

Blocked by: 02, 03

阶段：三 · 用户操作与生命周期

## 交付结果

两端在原卡片上维护当前会话的选中集合与锚点，悬停只展示授权可见的来源。

依据：[§2](../../../doc/会话附件操作插件需求Spec.md#2-点击哪张卡片取得哪份文件)、[§3](../../../doc/会话附件操作插件需求Spec.md#3-卡片和操作对象)、[§3.2](../../../doc/会话附件操作插件需求Spec.md#32-悬停路径提示)。对应验收用例 04、13。

## 验收条件

- [ ] 按用例 04 逐步核对 A–D，包括右键是否移动锚点、Ctrl 取消后再 Shift、无锚点选择和集合收缩。
- [ ] 滚动重绘保留选择；Ctrl+A 加载完整历史，失败保留原集合；Esc、切换、刷新、卸载清空状态。
- [ ] 提示可换行并随主题切换，远端有标识，仅副本时显示无源路径；无下载、缓存创建或剪贴板写入。
- [ ] 输入框、编辑器及文本选区保持宿主复制；单击只选中，键盘焦点可确定单项操作对象。

## 分支、提交与合入

按可验证行为提交，相关实现、测试和必要文档同次提交。提交或 PR 标题示例：`feat(core): select session attachments`。合回 `windows-one` 前同步集成分支，复跑本票及受共享契约影响的验证。在 Comments 记录实际提交号、验证结果和证据位置。
