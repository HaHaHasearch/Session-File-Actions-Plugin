## 交付结果

从两端原卡片保存单项或当前会话的选中集合，并显示实际落盘结果。

依据：[§3](../../../doc/会话附件操作插件需求Spec.md#3-卡片和操作对象)、[§4](../../../doc/会话附件操作插件需求Spec.md#4-批次反馈与生命周期)。对应验收用例 06。

## 验收条件

- [ ] 单项可改名，多项只选一次目录且按会话顺序平铺。
- [ ] 已有报告.pdf 时新文件为报告 (2).pdf；包含并发竞争和后缀已占用场景，原文件字节不变。
- [ ] 拒读或写入失败时继续其余项；取消对话框不写文件，中途取消保留成功项且无半成品。汇总成功、失败、取消数及实际文件名。

## 分支、提交与合入

确认前置票 05、06、07、08 已合入 `windows-one` 后，从该集成分支开 `save-files`。

按可验证行为提交，相关实现、测试和必要文档同次提交。提交或 PR 标题示例：`feat(desktop-files): save selected attachments`。合回 `windows-one` 前同步集成分支，复跑本票及受共享契约影响的验证。在 Comments 记录实际提交号、验证结果和证据位置。
