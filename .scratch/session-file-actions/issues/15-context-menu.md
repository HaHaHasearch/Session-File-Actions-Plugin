## 交付结果

在两端把已实现的动作接入完整单选和多选菜单。

依据：[§3.1](../../../doc/会话附件操作插件需求Spec.md#31-右键菜单设计)、[§3.2](../../../doc/会话附件操作插件需求Spec.md#32-悬停路径提示)。对应验收用例 09、11。

## 验收条件

- [ ] 按 Spec 核对六条命令、数量、顺序和分组；保留非重复宿主命令，禁用项的原因可通过键盘读取。
- [ ] 菜单键和 Shift+F10 沿用右键规则，方向键与 Enter 操作，Esc 逐级关闭并恢复焦点；菜单打开时冻结对象，切换聊天关闭旧菜单。
- [ ] 验证窗口边缘、系统缩放、滚动子菜单、父行高亮；宿主与系统主题相反时跟随宿主，运行中切换主题同步更新。
- [ ] 打开菜单不下载附件、不改剪贴板；单次选择只执行一次。
