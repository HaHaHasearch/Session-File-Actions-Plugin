# 14 在资源管理器定位选中的文件

Status: ready-for-agent

Blocked by: 05, 06, 07, 08

阶段：三 · 用户操作与生命周期

## 交付结果

从原卡片进入对应的本地目录并选中实际文件，支持跨目录和本地副本。

依据：[§3](../../../doc/会话附件操作插件需求Spec.md#3-卡片和操作对象)、[§3.1](../../../doc/会话附件操作插件需求Spec.md#31-右键菜单设计)、[§4](../../../doc/会话附件操作插件需求Spec.md#4-批次反馈与生命周期)。对应验收用例 07、10、12。

## 验收条件

- [ ] 同目录 A、B 一次展示并同时选中，另一目录另选 C；移走 B 后报告 B，仍能定位 A、C。
- [ ] 本地路径定位原文件，远端及会话来源定位标明的本地副本；切换聊天仍可访问，退出后占用副本延后清理。

## 分支、提交与合入

确认前置票 05、06、07、08 已合入 `windows-one` 后，从该集成分支开 `locate-files`。

按可验证行为提交，相关实现、测试和必要文档同次提交。提交或 PR 标题示例：`feat(desktop-files): reveal selected files`。合回 `windows-one` 前同步集成分支，复跑本票及受共享契约影响的验证。在 Comments 记录实际提交号、验证结果和证据位置。
