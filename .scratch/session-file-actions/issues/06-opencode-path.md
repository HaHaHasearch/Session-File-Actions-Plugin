# 06 复制 OpenCode 新旧消息中的路径附件

Status: ready-for-agent

Blocked by: 03, 04

阶段：二 · 单文件与附件来源

## 交付结果

从当前及历史消息的真实文件卡片复制关联路径的当前文件，复用已验证的系统发布能力。

依据：[§2](../../../doc/会话附件操作插件需求Spec.md#2-点击哪张卡片取得哪份文件)、[§4](../../../doc/会话附件操作插件需求Spec.md#4-批次反馈与生命周期)。对应验收用例 01、03、07（路径来源）。

## 验收条件

- [ ] 旧消息无新增字段也可复制；本地路径修改后按当前内容验哈希。
- [ ] 远端路径在所属 Host 授权后传回内容；断连、删除及拒读时不触碰原剪贴板。
- [ ] 路径与副本并存时核对路径优先；路径失效不可改读副本。真实并存样本缺失时标明未验证。

## 分支、提交与合入

确认前置票 03、04 已合入 `windows-one` 后，从该集成分支开 `opencode-path`。

按可验证行为提交，相关实现、测试和必要文档同次提交。提交或 PR 标题示例：`feat(opencode): copy referenced files`。合回 `windows-one` 前同步集成分支，复跑本票及受共享契约影响的验证。在 Comments 记录实际提交号、验证结果和证据位置。
