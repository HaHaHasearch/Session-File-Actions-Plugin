# 03 加载 OpenCode 预构建包并识别原消息卡片

Status: ready-for-agent

Blocked by: 01

阶段：一 · 工程和宿主基础

## 交付结果

通过全局插件配置加载预构建目录，使窗口和主进程能从原消息卡片识别操作对象。

依据：[§1.2](../../../doc/会话附件操作插件需求Spec.md#12-windows-插件安装说明)、[§2](../../../doc/会话附件操作插件需求Spec.md#2-点击哪张卡片取得哪份文件)。对应验收用例 04、05、13（OpenCode 接入）。

## 验收条件

- [ ] 在桌面自带后台服务器验证 GUI 导出及两个进程入口，无开发机源码引用。
- [ ] 两张同名文件卡片返回不同的持久消息与文件项；普通文本链接和无稳定身份的回显无文件入口。
- [ ] 卸载、重载后无重复贡献；分别记录官方基线和匹配验证构建能到达的入口。
