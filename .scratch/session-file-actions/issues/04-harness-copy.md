# 04 从 Harness 交付卡片复制当前文件

Status: ready-for-agent

Blocked by: 02

阶段：二 · 单文件与附件来源

## 交付结果

从一张交付卡片打通会话授权、准备本地副本、系统文件列表发布及真实粘贴。

依据：[§2](../../../doc/会话附件操作插件需求Spec.md#2-点击哪张卡片取得哪份文件)、[§3](../../../doc/会话附件操作插件需求Spec.md#3-卡片和操作对象)、[§4](../../../doc/会话附件操作插件需求Spec.md#4-批次反馈与生命周期)。对应验收用例 01、03、05。

## 验收条件

- [ ] 用二进制样本在 Windows 资源管理器粘贴，记录文件名及 SHA-256；改写源文件后再复制得到新内容。
- [ ] 准备后源文件再次改变不影响本次粘贴；路径失效或无权读取时指出失败项，保留预置剪贴板。
- [ ] 主进程只接受经会话授权的请求；系统确认写入后才提示成功。

## 分支、提交与合入

确认前置票 02 已合入 `windows-one` 后，从该集成分支开 `harness-copy`。

按可验证行为提交，相关实现、测试和必要文档同次提交。提交或 PR 标题示例：`feat(harness): copy a deliverable file`。合回 `windows-one` 前同步集成分支，复跑本票及受共享契约影响的验证。在 Comments 记录实际提交号、验证结果和证据位置。
