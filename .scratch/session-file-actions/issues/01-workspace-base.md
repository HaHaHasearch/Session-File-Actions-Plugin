# 01 建立可复现的工作区并验证附件身份

Status: ready-for-agent

Blocked by: None

阶段：一 · 工程和宿主基础

## 交付结果

从干净检出建立 pnpm 工作区，用生产入口验证同一会话中的附件身份。

依据：[§2](../../../doc/会话附件操作插件需求Spec.md#2-点击哪张卡片取得哪份文件)。对应验收用例 01、02、04（身份部分）。

## 验收条件

- [ ] 锁文件冻结安装、类型检查、相关 Vitest 测试均通过，命令可在干净环境复现。
- [ ] 两条消息中的同名附件可分别选择；同一卡片重绘后身份稳定，即使字节相同也不合并两个出现位置。

## 分支、提交与合入

先核对暂存、未暂存和未跟踪文档，仅将确认属于定稿基线的内容单独提交；从该基线建立集成分支 `windows-one`，再开 `workspace-base`。

按可验证行为提交，相关实现、测试和必要文档同次提交。提交或 PR 标题示例：`chore(workspace): establish reproducible builds`。合回 `windows-one` 前同步集成分支，复跑本票及受共享契约影响的验证。在 Comments 记录实际提交号、验证结果和证据位置。
