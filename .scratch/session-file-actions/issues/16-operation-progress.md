# 16 耗时操作的进度、取消和卸载清理

Status: ready-for-agent

Blocked by: 09, 11

阶段：三 · 用户操作与生命周期

## 交付结果

在发起会话展示复制与保存的阶段、数量、取消入口和最终结果。

依据：[§4](../../../doc/会话附件操作插件需求Spec.md#4-批次反馈与生命周期)。对应验收用例 08、14。

## 验收条件

- [ ] 切换到 B 不取消 A 的操作，返回 A 可查看进度及结果，B 不出现旧提示。
- [ ] 复制准备中取消或卸载保留原剪贴板；进入系统发布阶段后结束取消入口。
- [ ] 批量保存完成首项后取消或卸载，只清理本次未完成文件，保留成品并核对计数。
- [ ] 提交系统操作后丢失回执再卸载，重载能查看结果未确认且不重放；释放订阅，重载后按一次 Ctrl+C 只执行一次。
